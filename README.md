# Bill: Viaje hacia el Sol — Edición Expedición

Aventura fan no oficial de nueve desafíos, sin instalación ni dependencias externas.

## Jugar
Abre `index.html` en un navegador moderno. El progreso se guarda localmente por origen y navegador.

## Publicar
Sube `index.html` a la raíz de la rama `main` de un repositorio público. En Settings → Pages, selecciona Deploy from a branch → main → / (root) y guarda.

## Edición de publicación
Modo de pruebas desactivado (`TEST_MODE=false`). No se ofrece el salto de niveles. La tarjeta final conserva el mensaje provisional: edita `const REWARD` para personalizarla. El contenido y las soluciones son visibles en el código fuente; no incluyas datos privados.

El mus es una adaptación digital simplificada. Pokémon y el personaje original utilizado como imagen de Bill pertenecen a sus titulares; esta aventura no está afiliada a ellos. Comprueba los derechos necesarios para distribuir la imagen del personaje.
